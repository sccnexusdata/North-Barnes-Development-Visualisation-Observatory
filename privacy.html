Privacy

Minimal collection by design.

The Observatory is a static public-interest website. It has no account system, no public contact form and no first-party analytics configured in the current public export.

3D requests are opt-in

Third-party mapping and terrain requests begin when you choose to enter the live 3D experience, not merely because the evidence page exists.

What happens when you use the site

Normal page viewing

GitHub Pages serves the static site. Standard web-server/network metadata, including IP address and browser request information, may be processed by the hosting infrastructure in the normal course of delivering the page. The Observatory itself does not create user accounts or ask for personal details.

A service worker may store Observatory files locally in your browser so that the site is resilient on poor connections. This cache contains public site assets, not a user profile.

Entering the 3D viewer

The live terrain viewer can request MapLibre code from jsDelivr or unpkg, OpenStreetMap raster tiles from tile.openstreetmap.org, and Terrarium elevation tiles from Amazon S3/AWS Open Data. Those external services receive the technical information required to answer the request, which normally includes your IP address.

The project does not use those requests to build a behavioural profile. Third-party services remain governed by their own privacy and usage terms.

Cookies, analytics and changes

The current public export does not set first-party advertising or analytics cookies. If analytics, embedded media or additional external services are introduced later, this notice must be updated before publication and the release will remain visible through release provenance.

If you prefer not to contact the 3D providers, you can read the proposal, evidence and verification material without entering the immersive viewer.
